- **2026-08-25 (4)** — **kb-eval redesigned — the harness could not detect a bad judge, and that was a design fault, not a bug.** Root cause: v1 let the judge submit its own `score`/`verdict`, so nothing anchored the number — the audit got 1.0/pass accepted for a case whose note had been deleted.
